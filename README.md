# Using Association Rule Learning to Identify Inventory Gaps in Wholesale Distribution Networks

Undergraduate thesis completed at the University of Toronto (2026), supervised by Professor Yuri Lawryshyn, exploring how machine learning and transactional data analysis can improve inventory management in wholesale distribution.


The project combines **Association Rule Learning (FP-Growth)**, **product clustering (HDBSCAN and K-Means)**, and **network analysis** to identify primary demand-driving products and their complementary secondary products. The resulting mappings help identify inventory stocking gaps and products at risk of obsolescence.

## Technologies
- Python
- Pandas, mlxtend, scikit-learn
- NetworkX
- Apache Spark, Databricks, Snowflake
